# Code of Conduct

## Our pledge

We want this project to be a place where anyone can contribute — whatever their
background, experience level, or field. Physicists, software engineers and people
who arrived here because an agent suggested a skill are all equally welcome, and
none of them should have to prove they belong before being taken seriously.

## Expected behaviour

- Assume competence. A question that looks basic in your field is often expert
  work in the asker's.
- Critique the work, not the person. "This observable cannot resolve a
  three-fold degenerate phase" is useful; "you clearly do not understand
  Rydberg physics" is not.
- Say what you know and how you know it. This repository runs experiments on real
  hardware that costs real allocation time — a confident guess presented as a
  measurement wastes someone's shots.
- Accept a correction without treating it as a loss.

## Unacceptable behaviour

Harassment, insults, or discriminatory language of any kind. Publishing others'
private information. Sustained disruption of discussions or review. Sexualised
language or imagery, and unwelcome sexual attention.

## Scope

This applies in issues, pull requests, commit messages, code comments and any
other project space, including when representing the project elsewhere.

## Enforcement

Report a concern privately to the repository maintainers via **Security → Report
a vulnerability**, which is the only private channel this repository has. Reports
are handled confidentially. Maintainers may warn, remove content, or block a
contributor, and will say which action they took and why.

Maintainers are held to this document too. If a maintainer is the problem,
report it to another one.
